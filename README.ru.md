# AIDM Web

[English](README.md) | Русский

Локальный мастер для текстовых ролевых игр в браузере. Приложение работает с любой LLM через OpenAI-совместимый API (по умолчанию — [LM Studio](http://localhost:1234)). Телефон в той же сети Wi-Fi или в той же сети Tailscale открывает эту страницу.

Этот репозиторий — веб-версия. Старая настольная программа лежит в [AIDM_Desktop](AIDM_Desktop/README.ru.md) и больше не является текущей сборкой.

## Релиз

1. Из корня репозитория запустите `build_web.ps1`.
2. Скрипт соберёт `App_web/`: внутри `AIDM.exe` и папка `worlds/` рядом с ним.
3. Упакуйте `App_web` в zip и распакуйте архив в любую папку.
4. Запустите `AIDM.exe`.
5. Выберите, откуда открывать игру: только этот компьютер, домашний Wi-Fi или Tailscale.
6. Окно консоли не закрывайте. Если закрыть его, сервер остановится.
7. Запустите локальную модель. По умолчанию игра ждёт [LM Studio](http://localhost:1234).

Миры, созданные в программе, сохраняются в `worlds` рядом с `AIDM.exe`. Эта папка уезжает вместе с архивом. Сборка не копирует уже существующие кампании и ключи API: `worlds/settings.json` в архиве — пустой шаблон.

## Запуск из исходников

```text
pip install -r requirements.txt
python run_web.py
```

При запуске из исходников миры остаются в `worlds`. Рядом с программой они лежат только у собранного exe.

## Сеть

Первое окно спрашивает, откуда открывать игру. Выбор запоминается.

| Вариант | Кто откроет страницу |
|---------|----------------------|
| Только этот компьютер | Этот ПК, адрес `http://127.0.0.1:8765` |
| Домашняя сеть Wi-Fi | Устройства в той же сети Wi-Fi. Адрес показан в окне. |
| Tailscale | Устройства в той же сети Tailscale. Tailscale должен быть запущен до нажатия «Запустить». Общий Wi-Fi не нужен. |

Сервер занимает порт **8765**. Если телефон не открывает страницу, разрешите входящий TCP 8765 в брандмауэре Windows. Компьютер должен оставаться включённым.

## Игра

После «Запустить» страница открывается в браузере.

- **Меню** открывает миры, файлы мира, карточки, память, настройки, последний промпт и промпт сцены.
- **Сделать ход** показывает поле и кнопку «Отправить». **Дальше?** спрашивает направление и продолжает сцену.
- **Отмена**, **Ещё раз** и **Редактировать** работают с последними репликами.
- Полоса под текстом показывает, насколько контекст заполнился с последней суммаризации.
- Мир можно выгрузить и загрузить zip-архивом его файлов. Настройки программы в архив не входят.

Карточки, банк памяти, суммаризация и поля настроек устроены так же, как в [старой настольной программе](AIDM_Desktop/README.ru.md).
