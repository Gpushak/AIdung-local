# 🐉 AI Dungeon Master

[🇬🇧 English](README.md) | [🇷🇺 Русский](README.ru.md)

(Завайбкоженая версия ai dungeon для запуска с локальной моделью)
Локальный мастер для текстовых ролевых игр. Приложение работает с любой LLM через OpenAI-совместимый API (по умолчанию — [LM Studio](http://localhost:1234)).


Если играете на русском, советую использовать модели gemma 4 (Они отлично пишут на русском и хорошее соотношение вес/качество), я использую в основном 31b или 26b a4b.

## Возможности

- **Текстовая RPG-сессия** — вы описываете действия, ИИ отвечает от лица мастера
- **Миры** — каждый мир хранится в отдельной папке с настройками, историей и памятью
- **Карточки историй** — заметки с триггерами; релевантные карточки подтягиваются в промпт автоматически
- **Банк памяти** — ИИ индексирует прошлые ходы и подставляет нужные воспоминания по ключевым словам
- **Автосуммаризация** — периодическое сжатие хроники в `summary.txt`
- **Потоковый ответ** — ответ мастера появляется по мере генерации
- **Остановка генерации** — можно прервать ответ, суммаризацию или индексацию памяти
- **Промпты изображения сцены** — промпт и антипромпт по последним ходам и карточкам истории
- **Управление контекстом** — подсчёт токенов, обрезка истории под размер окна модели

## Запуск

1. Установите релиз и распакуйте в отдельную папку.
2. Запустите exe.
3. Запустите локальную модель и локальный сервер.

## Размещение окон

Главное окно открывается по центру экрана, а все диалоги — по центру главного окна. Если окно не
помещается (например 900×1200 на экране 1080p), оно уменьшается до рабочей области, а не уезжает
за верхний край. Внизу резервируется место под панель задач Windows, чтобы окна не оказались под ней.

## Быстрый старт

1. При первом запуске создайте мир через кнопку **➕** или **🔄 Миры → Создать**.
2. Заполните вкладки: инструкции ИИ, основы сюжета, авторские пометки, карточки историй (по желанию).
3. Заполните вкладку вступления, где опишите ситуацию, где хотите начать историю.
4. Напишите действие в поле ввода (или оставьте его пустым) и нажмите **▶ Отправить** (или Enter).
5. При необходимости откройте **⚙️ Настройки ИИ** и подстройте температуру, размер контекста и интервалы.

## Остановка генерации

Пока ИИ работает, кнопка **▶ Отправить** превращается в красную **⏹ Стоп** (работает и клавиша **Esc**).
Она прерывает то, что выполняется в данный момент:

- **Генерация ответа** — уже полученная часть текста сохраняется в историю, её можно отредактировать или удалить кнопкой **⏪ Отменить ход**. Фоновые суммаризация и индексация памяти не запускаются.
- **Суммаризация / индексация памяти** — операция отменяется, `summary.txt` и `memory_bank.json` остаются без изменений, задача повторится через несколько следующих ходов.
- **Промпт сцены** — генерация отменяется, окно не открывается.

Окно с готовым промптом **не модальное**: можно скопировать текст, переключиться в программу для
генерации картинок (Automatic1111, ComfyUI, Midjourney) и вернуться в игру, ничего не закрывая.

Под логом переписки постоянно висит полоска заполнения контекстного окна. Она желтеет на 70% и краснеет
после 90% — видно, когда пора суммаризировать или заводить новую кампанию.

## Промпты изображения сцены

Кнопка **🎨 Промпт сцены** собирает готовый промпт для генерации изображения текущей сцены. В контекст для модели попадает:

- файл `plot_basics.txt`, а также инструкции ИИ и авторские пометки
- **последние 5 завершённых ходов** — каждый ответ мастера вместе с ходом игрока перед ним
- **релевантные карточки истории**, найденные по ключевым словам из этих ходов, плюс все карточки без триггеров (всегда активные)

Модель возвращает один JSON-объект с полями `prompt` и `negative_prompt`. Оба показываются в окне
с отдельными кнопками копирования. Ограничения по содержанию сняты: NSFW, насилие и эротические
элементы разрешены, если они соответствуют сцене.

Если модель не выдала корректный JSON, исходный ответ показывается как промпт.

### Формат промпта

Разные модели ожидают разную разметку, поэтому формат выбирается в **⚙️ Настройки ИИ → Формат промпта для изображений**:

| Формат | Как выглядит промпт |
|--------|---------------------|
| **Stable Diffusion** (по умолчанию) | теги через запятую как у бустимилков, веса `(тег:1.2)`, теги качества в конце |
| **Midjourney** | один английский абзац и параметры `--ar 16:9 --style raw --v 7` |
| **Flux** | 2–4 английских предложения, без весов и тегов качества |
| **Универсальный** | 2–4 английских предложения, без весов |

Настройка хранится в `worlds/settings.json` под ключом `image_prompt_style` (`sd`, `midjourney`, `flux`, `generic`).
Выбранный формат показывается над промптом в окне результата.

## Структура мира

Каждый мир — папка в каталоге `worlds/`:

```
worlds/
├── settings.json              # Глобальные настройки приложения
└── Название мира/
    ├── ai_instructions.txt    # Системные инструкции для мастера
    ├── plot_basics.txt        # Сеттинг и завязка
    ├── author_notes.txt       # Стиль, тон, пожелания автора
    ├── summary.txt            # Сжатая хроника (обновляется автоматически)
    ├── story_cards.json       # Карточки историй
    ├── memory_bank.json       # Банк памяти
    └── history.json           # История текущей сессии
```

### Безопасное сохранение

Все файлы пишутся атомарно: данные сначала попадают во временный файл и сбрасываются на диск, предыдущая
версия копируется в `<файл>.bak`, и только потом временный файл переименовывается на место. Поэтому сбой
питания или кончившееся место во время сохранения не оставят обрезанный файл.

Если при запуске файл оказывается нечитаемым, сначала пробуется `<файл>.bak`. Когда и резервная копия
бита, **мир не загружается и показывается ошибка** — повреждённый `history.json` никогда молча не
превратится в пустую кампанию. Банк памяти и карточки в этом случае откатываются к значениям по
умолчанию, потому что их можно пересоздать.

## Карточки историй

Карточки заменяют старый файл `characters.txt`. Каждая карточка содержит:

- **Название** — заголовок (персонаж, локация, фракция и т.д.)
- **Описание** — подробная информация для ИИ
- **Триггеры** — ключевые слова через запятую

При каждом ходе в промпт попадают карточки, чьи триггеры совпали с вводом игрока и недавней историей. **Пустые триггеры** означают, что карточка всегда активна.

Пример `story_cards.json`:

```json
{
  "cards": [
    {
      "id": "card_001",
      "title": "Арион",
      "description": "Арион это искатель приключений и воин. Носит кожаную броню...",
      "triggers": ["арион", "герой", "воин"]
    },
    {
      "id": "card_002",
      "title": "Таверна «Пьяный дракон»",
      "description": "Шумное заведение на окраине города...",
      "triggers": ["таверна", "дракон", "бармен"]
    }
  ]
}
```

## Банк памяти

Каждые N ходов (по умолчанию — 5) ИИ анализирует новый фрагмент сессии и сохраняет запись с:

- кратким описанием событий;
- ключевыми словами;
- локацией и упомянутыми NPC.

При следующих ходах релевантные воспоминания добавляются в промпт. Это помогает не забывать детали длинных кампаний.

## Суммаризация

Каждые N ходов (по умолчанию — 10) ИИ обновляет `summary.txt` — сжатую хронику всей истории. Файл учитывает предыдущее summary, поэтому важные факты сохраняются даже когда свежая история обрезается из-за лимита контекста.

Автосуммаризацию и банк памяти можно отключить кнопками в верхней панели или в настройках. Ручные кнопки **📝 Суммаризация** и **🧠 Память** работают независимо от автоматики.

## Настройки ИИ

Глобальные параметры хранятся в `worlds/settings.json`, можете менять через файл или в приложении:

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `temperature` | `0.7` | Креативность ответов |
| `max_tokens` | `300` | Максимум токенов в ответе |
| `context_size` | `16384` | Размер контекстного окна модели |
| `summary_interval` | `10` | Автосуммаризация каждые N ходов |
| `memory_interval` | `5` | Индексация памяти каждые N ходов |
| `memory_top_k` | `5` | Сколько воспоминаний/карточек подставлять в промпт |
| `stream_mode` | `true` | Показывать ответ по мере генерации |
| `image_prompt_style` | `sd` | Формат промпта для изображений: `sd`, `midjourney`, `flux`, `generic` |
| `summary_enabled` | `true` | Автосуммаризация вкл/выкл |
| `memory_enabled` | `true` | Банк памяти вкл/выкл |

## Советы

- Для длинных кампаний держите включёнными суммаризацию и банк памяти.
- Выносите места, персонажей и другое, что бы вы хотели бы видеть в мире, в карточки историй.
- Используйте **📋 Промпт**, чтобы понять, что именно видит модель на каждом ходе.
